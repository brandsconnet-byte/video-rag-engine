# Web UI Installation & Usage

## Installation

```bash
# Install Flask
pip install flask

# Start the web server
python app.py
```

Then open: **http://localhost:5000**

## Features

✅ **Upload Video** - Drag & drop or click to upload
✅ **Select Config** - Choose Fast/Balanced/Accurate
✅ **Real-time Progress** - Watch processing in real-time
✅ **Search Scenes** - Search with natural language
✅ **View Results** - See matching scenes with timestamps
✅ **Extract Clips** - One-click clip extraction
✅ **Auto-routing** - Intelligent FFmpeg/auto-editor selection

## How It Works

1. **Upload** → Select video + config profile
2. **Process** → AI indexes scenes (45-120 min)
3. **Search** → Find scenes by query
4. **Extract** → Download optimized clips
